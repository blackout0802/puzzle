# イラスト案（見本）

`index.html` は、同じ3つの下絵（しょうぼうしゃ・ライオン・しんかんせん）を、10通りの画風で描き分けた見本です。アプリ本体（`app/`）のイラストは変更していません。

画風は SVG のフィルター（にじみ・ざらつき・立体・縫い目など）で自動的に切り替えています。形は共通なので、採用が決まった画風は、その画風に合わせて形から描き起こし直して本番の絵にします。

採用候補（番号は固定）: 3 切り紙 / 4 ぷっくり（クレイ） / 5 ステッカー / 6 ミッドセンチュリー / 7 図鑑 / 9 フェルト / 11 ちぎり絵（和紙） / 12 刺繍 / 13 木のおもちゃ / 14 ゆるい線画（ずらし塗り） / 15 ジオラマ（ミニチュア）

除外（コードは `hidden:1` で残してある）: 1 水彩 / 2 クレヨン / 8 ドット絵 / 10 ステンドグラス

## アニメ調（`anime.html`）
同じ3つの下絵を、アニメ調の10通りの雰囲気（青空と光／ほのぼの日常系／90年代セル／魔法少女／少年バトル／夕焼け／夜景ネオン／ちびキャラ／劇場版シネマ／メカ）で描き分けた見本。共通の処理は「本体色＋2色の影＋ハイライト＋線」（セル塗り）で、空の色・光・質感・線の太さを変えている。
