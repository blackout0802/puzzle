# ジグソーシール帳（仮）

幼児向けジグソーパズル。`index.html` を開くだけで動く（ビルド不要）。

## あそびかた（タップ＆タップ）
- ピース置き場のピースを **タップ** して選ぶ → 盤面の **置きたいマスをタップ**。
- **テーブル**（盤面の外の点線の内側）の空いている所をタップすると、ピースを仮置きできる。
- 選んだピースで、**つながるピースをタップ**するとくっつく（相手が盤面に置いたピースなら、そのまま盤面にはまる）。
- 仮置きしたピースは、となり同士で **かたまり** になる。かたまりをタップで持ち上げ、盤面の正しいマスをタップすると **まとめてはまる**。
- 位置が近ければ自動でくっつく（許容範囲は難しさで変わる）。まちがいは数えるだけで、叱らない。
- かたまりを持ち上げると「おきばへ もどす」が出る（元の並び順でピース置き場に戻る）。
- 「あそびかた」はホームと、ゲーム画面のピース置き場の上にあるボタンから開ける（開いている間は時間を止める）。
- 盤面はピンチで拡大、1本指で移動。⤢ ボタンは 盤面ぜんたい → テーブルぜんたい。右上の見本をタップで大きく表示。

## 追加した機能
- **写真のきりとり**: 写真を取り込むと「きりとり」画面。ゆびで動かす／2本でつまんで拡大・縮小／形（そのまま・しかく・よこ・たて・ワイド）。あとから「きりとりを なおす」で直せる
- **つぎは これ！**: 最後にクリアした記録（時間・まちがい）から、ピース数・むずかしさ・絵をおすすめ。ボタンに「おすすめ」の印
- **声のガイド**: ひらがなで はなしかける（はじめ・はんぶん・ふちが できた・あと10 など）。設定でオフにできる。`PZ.sayV`
- **ずかん**: クリアした のりもの・どうぶつが ひらく。タップで説明を読み上げ
- **あそんだ記録と きゅうけい**: 設定に7日分の棒グラフ。10〜30分で「ちょっと きゅうけい しよう」（なし も選べる）
- **プロフィール**: 5人まで。シール・つづき・ベストタイム・記録を子どもごとに分ける（写真は共有）
- **えを かく**: ゆびで描いた絵をパズルに（写真と同じ形で保存されるので、きりとり等もそのまま使える）
- **ふちガイド**: やさしい／ふつうで40ピース以上のとき、盤面のまわりを光らせ、置き場を「ふち」から表示
- **バックアップ**: 設定から JSON に書き出し／読み込み（写真・シール・プロフィール・記録）
- **ストア公開の準備**: `../store/`（アイコン・プライバシーポリシー・掲載文・チェックリスト）、`../capacitor/`（アプリ化の設定）

## ファイル
- `js/engine.js` … 盤面・テーブル・かたまり・拡大移動・ヒント・途中保存
- `js/ui.js` … ホーム、写真の取り込み、クリア演出、シール帳、保護者設定
- `js/store.js` … 端末内保存（IndexedDB + localStorage）。写真・シールは外部に送らない
- `js/common.js` … 絵（SVG）・効果音・ジグソー形状・保護者ゲート

## 絵
- `js/art-vehicles.js` … 追加の絵。のりもの（消防車・パトカー・救急車・ショベルカー・新幹線・ダンプカー・バス・飛行機・ごみ収集車・ミキサー車・クレーン車・トラクター・SL・ヘリコプター。くるま・ロケットも のりもの扱い）と、どうぶつ・きょうりゅう（ティラノサウルス・トリケラトプス・ライオン・ぞう・きりん・パンダ）。
- 「特徴のないピース」対策：パズルを作るとき、空・水・地面・道路など のっぺりしたマスを自動で見つけて、絵に合う小さな絵柄（雲・鳥・泡・花・星など）を足す（`engine.js` の `enrichSource`）。写真には足さない。
- 「のりもの ぜんぶ」「どうぶつ・しぜん ぜんぶ」は、複数の絵をタイル状に並べたパズル。

## 1ファイルにまとめる（配布用）
```
python3 tools/build_single_html.py   # → dist/jigsaw-sticker-book.html（CSS・JSを埋めこんだ単体HTML。外部通信なし）
```
- そのままブラウザで開ける。メール添付やファイル共有、自分のWebサイトへの設置にも使える。
- 写真・シール・途中経過は、開いた端末のブラウザに保存される（ファイルを開く場所＝URLごとに別の保存領域）。
- iPhone で「ファイルを直接開く」と保存が効かないことがあるため、Web に置いて https で開くのがおすすめ（GitHub Pages / Netlify / Cloudflare Pages など無料の置き場所がある）。
