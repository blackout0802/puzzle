# ストア公開チェックリスト

`docs/research.md` の調査内容を、実際の手順に並べ直したものです。**期限や要件は変わるので、申請直前に公式ページで確認**してください（⚠️は特に要確認）。

## A. 先にやること（アプリ側・済んでいるもの）
- [x] 広告なし・解析なし・アカウントなし・通信なし
- [x] 保護者ゲート（写真取り込み・設定）
- [x] プライバシーポリシー本文（`store/privacy-policy.html`）＋アプリ内の表示（設定 → プライバシー）
- [x] アイコン（`store/icon.svg` と PNG）
- [x] 掲載文の下書き（`store/listing.md`）
- [x] アプリ化の設定ファイル（`capacitor/`）
- [ ] **連絡先メールアドレスを決めて**、`privacy-policy.html` と `listing.md` に記入
- [ ] **プライバシーポリシーを公開 URL に置く**（GitHub Pages などの無料の場所でよい）
- [ ] **appId を決める**（`capacitor/capacitor.config.json`。後から変更できない）
- [ ] 権利の確認: 絵（SVG）・音（自作の合成音）・フォントはすべて自作／システム標準 → OK。写真を載せる場合は本人のものだけ

## B. Google Play
1. [ ] Play Console に登録（25 ドル・本人確認）⚠️ 個人の場合、住所が公開される場合あり
2. [ ] アプリ作成 → 「子ども向け／ファミリー」の質問に回答
3. [ ] AAB を作成（`capacitor/README.md` 参照）。**Target API は最新の要件を確認** ⚠️
4. [ ] データセーフティ・コンテンツのレーティング・広告なしの申告（`store/listing.md` の表）
5. [ ] **クローズドテスト: 12 人以上 × 14 日連続**（2023/11/13 以降に作った個人アカウントの場合）⚠️
   - 家族・親戚・友人にテスターになってもらう（Google アカウントが必要）
   - 途中で 12 人を割るとやり直しになるので、15〜20 人集めておくと安心
6. [ ] 本番公開を申請

## C. App Store（Apple）
1. [ ] Apple Developer Program に登録（99 ドル/年）。個人だと本名が販売元として表示される
2. [ ] **Mac と Xcode が必要**（Mac が無いときはクラウドビルドを検討）⚠️
3. [ ] App Store Connect でアプリを作成。カテゴリは「キッズ（5 歳以下）」を推奨
4. [ ] App Privacy は「データを収集しない」
5. [ ] プライバシーポリシー URL（App Store Connect とアプリ内の両方）
6. [ ] スクリーンショット、説明、キーワード、サポート URL
7. [ ] TestFlight で実機テスト → 審査に提出
8. [ ] 審査メモ（`store/listing.md`）を貼る

## D. 提出前の実機テスト（必須）
- [ ] iPhone と Android それぞれで、**ホーム → 24 ピースをクリア → シール帳**
- [ ] 写真を取り込み、**アプリを閉じて開き直しても残っている**
- [ ] 写真の向き（縦撮り）が正しい
- [ ] 音・声が出る／「おと なし」で全部止まる
- [ ] 300 ピースで動作が重くない（古い端末でも）
- [ ] 画面を横向き・タブレットにしても崩れない
- [ ] 機内モードで、全機能が動く
- [ ] バックアップの書き出し・読み込み

## E. 公開後
- [ ] レビューの確認、不具合の修正は `app/` を直して `npm run sync` → 新しいバージョンで再提出
- [ ] 副業規定（会社員の場合）・税金（収益が出る場合）⚠️
